夸克 / UC / 115 / 123 / 光鸭 / 天翼，自动追剧该选哪个网盘？

2026-10-29 更新 · 附一手实测资源量数据 （已更新：新增 UC 网盘支持、光鸭扫码登录与 v2026.10.29 多盘统一协作架构）

用 巡影 Mediary Scout 做网盘自动追剧，网盘选型直接决定成功率：核心不在于「哪家宣称下载速度最快」，而在于你要追的电影、剧集、番剧，在这个网盘生态里有没有存量分享链接，或者这个网盘能不能直接秒传磁力链。如果资源池是空的，再聪明的 AI Agent 也巧妇难为无米之炊。

下面这组数据来自我们在生产环境用同一套搜索源实测的一手记录，同时说明为什么不建议选阿里云盘和移动云盘。

一、实测：同样的片单，六大网盘能用的资源池有多大？

采样口径说明

横跨电影、热播国产剧、美剧与日本番剧的代表性片单；使用同一个 PanSou 实例 + 海搜（Haisou）补充源。不同频道配置下绝对数值会有浮动，但各网盘之间的数量级梯队关系非常稳定。

网盘品牌自家分享链接数可离线秒传的磁力数总可用资源池核心特点
夸克网盘523—523分享链生态断层第一；但非会员仅 10GB 易超额
123网盘120361481分享 + 磁力双通道，免费账号可转存
115网盘100361461老牌磁力秒传之王，冷门老片与蓝光原盘命中率极高
光鸭云盘35+361396+迅雷系底层，磁力秒传快、空间大（常见 500TB），新兴 4K 剧集多
UC网盘141（活链 ~65）—~65与夸克同属阿里系协议，新剧 4K 分享多（会员常有 6TB 空间）
天翼云盘63—63国企背景稳定，剧集/动漫尚可，电影资源偏少

从实测数据可以直接得出三个关键结论：

  • 只看网盘分享链接，夸克断层第一，UC 是极佳的阿里系平替补充：夸克在公开资源站和频道里的发帖量最大；但很多早期开过夸克 SVIP（6TB）后来到期的用户，容量会退回 10GB（处于 已超额 -1.3TB 状态）。此时如果你有 UC 网盘（同套云盘协议，6TB 容量），就能直接吃下大量阿里系 4K 新剧分享链。
  • 支持「磁力离线秒传」的网盘（115 / 123 / 光鸭），总资源池会反超纯分享网盘：115 和 123 的自家分享链虽然不如夸克多，但一旦接上磁力链（尤其是配合 Prowlarr 索引器），可用池直接飙升到 460+，而且不依赖别人有没有发网盘分享帖。
  • 新剧热综看夸克/UC/光鸭，冷门老片与外语蓝光看 115/磁力：比如 2022 年电影《坠落 Fall》，公开分享链几乎全是同名日剧或续集假片，但 115 磁力通道能直接秒传 13.9GB 的 2160p UHD BluRay HDR 版本。

二、为什么「分享链 + 磁力双通道」这么关键？

检索器搜出来的资源分为两大通道：网盘分享链接（同品牌服务端复制转存）和磁力 / ed2k 链接（需要网盘提供离线下载接口）。六大网盘的通道能力与登录方式如下：

网盘分享链接转存磁力 / 离线下载登录方式外挂字幕自动落盘（assrt）
夸克网盘✅ 支持❌ 无网页磁力接口手机 App 扫码 / Cookie❌（仅内封或原包自带字幕）
UC网盘✅ 支持❌ 网页磁力需运行时加密签名手机 App 扫码 / Cookie❌（仅内封或原包自带字幕）
115网盘✅ 支持✅ 内置高速离线秒传手机 App 扫码 / Cookie✅ 支持整包批量落盘改名
123网盘✅ 支持✅ 内置离线下载手机 App 扫码 / Token（90天）✅ 支持逐文件流水线落盘
光鸭云盘✅ 支持光鸭分享链✅ 磁力 / ed2k / BT 秒传手机 App 扫码 / Token✅ 支持直链离线落盘
天翼云盘✅ 支持（个人云）❌ 不支持手机 App 扫码 / SSON❌（仅内封或原包自带字幕）

三、为什么不支持阿里云盘、移动云盘或百度网盘？

很多用户会问为什么列表里只有这六家。我们在接入每个新网盘前都有一套严格的五项准入评估（详见仓库 docs/drive-brand-evaluations.md）：

  • 阿里云盘（aDrive）：官方开放平台 API 明确不支持转存他人公开分享链接（实测调用直接返回 404），因此无法实现全自动追剧转存。
  • 中国移动云盘（139）：实测转存影视资源后，服务端会在后台静默和谐删除视频文件（内容留存一票否决），做媒体库会导致「表面入库、播放时文件已没」。
  • 百度网盘：非 SVIP 限速与播放挂载限制极严，且影视分享链极易秒和谐。

四、现在不用二选一：巡影 v2026.10.29 多网盘统一协作

重大架构升级：把你手上的网盘全部连上，Agent 自动统筹！

在早期版本中，不同网盘是隔离的工作区；而从 巡影 v2026.10.29 开始，Mediary Scout 升级为「统一多网盘协作获取」架构（详见 多网盘统一协作原理）：

  1. 实时剩余容量探测与超额禁写：设置页实时显示每块网盘的剩余空间。比如你的夸克会员过期显示 已超额 1.34 TB（共 10.0 GB），Agent 会自动将其排除在落盘目标之外，绝不往超额盘塞文件。
  2. 单盘优先收齐（绝不无故拆盘）：只要你连接的任意一块可用网盘能完整收齐当前缺集（比如光鸭或 115 有全集 4K 包），Agent 就只用那一块盘一次收齐，其余网盘连空目录都不会创建。
  3. 跨盘互补兜底（最大化集数覆盖）：只有当没有任何单块网盘能收齐全部集数时（例如《幻视任务》前 4 集 4K 杜比视界在 115、最新第 5–6 集只在 123 网盘有分享），Agent 才会自动跨 115 + 123 双盘互补收齐 6 集，并在剧集详情页的每个集数格子上清楚标出 已获取 · 115、已获取 · 123。
