夸克 / 115 / 光鸭 / 123 / 天翼，自动追剧该选哪个网盘？

2026-08-04 · 附实测资源量数据 （已更新：123网盘现已支持磁力离线下载）

做自动追剧这件事，网盘选错会直接决定成败：不是「哪个网盘容量大、速度快」，而是你要追的片子，在这个网盘的生态里有没有人分享。资源池空，再好的自动化也只能空转。

下面这组数字来自我们自己的实测，不是抄来的宣传口径。

两个直接结论：

  • 夸克的分享池最大，而且是断层领先 —— 只看单一来源的「有没有资源」，夸克赢。
  • 能吃磁力的网盘，总可用量会反超：123 和 115 自家分享链接分别只有 120 和 100，但它们都能走离线下载吃磁力，总池冲到 481 和 461 —— 双通道是决定性的。

为什么「能吃磁力」这么关键

PanSou 搜出来的资源分两类：网盘分享链接（转存到自己网盘）和磁力 / BT（要网盘支持离线下载）。各家能吃哪种，差别很大 —— 而磁力就是磁力，不管它是 PanSou 搜出来的还是 Prowlarr 索引器给的，只要网盘支持离线下载就都能接：

网盘分享链接转存磁力 / 离线下载
夸克✅❌ 无磁力网页 API
115✅✅ 内置离线下载
123网盘✅✅ 内置离线下载
光鸭云盘❌ v1 不支持✅ 仅磁力 / ed2k / BT
天翼云盘✅❌

注意光鸭云盘（迅雷系）是个特例：它只走离线下载，不转存分享链接。所以它适合跟 Prowlarr 这类磁力索引器搭配，单独用它去接 PanSou 的分享链接是不通的。

登录方式与免费账号

  • 夸克 / 115 / 123 / 天翼：扫码登录（天翼也支持粘贴 SSON cookie）。
  • 光鸭云盘：token 认证。
  • 123网盘：扫码拿到的 token 大约 90 天有效。

免费账号能用吗？能。

转存是服务端复制，不消耗你的下载流量配额 —— 所以 123 和天翼用免费账号也能跑自动转存。

不用只选一个。

Mediary Scout 把每个网盘当成独立工作区，可以同时接多个，搜索时按你当前所在的网盘去转存。实际用法通常是「夸克或 115 打主力，另一个补缺」。

下一步

选好网盘之后，剩下的事情是：让 agent 自己去搜、去转存、去核对缺集。

  • 回首页看它怎么工作（有演示动图）
