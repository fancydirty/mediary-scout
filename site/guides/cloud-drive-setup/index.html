夸克 / UC / 115 / 123 / 光鸭 / 天翼扫码连接与搜索源配置指南

2026-10-29 更新 · 全部六大网盘均已支持手机 App 扫码一键绑定

打开 巡影 Mediary Scout 的 设置 → 网盘连接，你可以同时添加一块或多块网盘。每次绑定成功后，系统会自动在你的网盘根目录下创建 Mediary Scout/{Movies,TV,Anime} 三个分类文件夹，并探测当前网盘的剩余容量。

一、六大网盘连接方式一览

1. 夸克网盘 & UC 网盘（扫码或粘贴 Cookie）

  • 扫码登录（推荐）：在「添加网盘」切到「夸克网盘」或「UC网盘」，点击「生成二维码」，打开手机上的夸克 App 或 UC 浏览器 App 扫码确认即可自动入库。
  • Cookie 粘贴兜底：也可在电脑浏览器登录 pan.quark.cn 或 drive.uc.cn，从开发者工具 Network 面板复制包含 __puus 与 __pus 的 Cookie 字符串粘贴绑定。

2. 115 网盘（扫码或粘贴 Cookie）

  • 在「添加网盘」切到「115 网盘」，点击生成二维码，用手机 115 生活 App 扫码并点击确认，系统会自动兑换网页会话并初始化分类目录。
  • 如果后续手机端踢掉了登录设备导致卡片显示「掉线 · 重新绑定即恢复」，只需用同一个 115 账号重新扫一次码即可原地恢复，历史追剧记录与目录 ID 均完好保留。

3. 123网盘（扫码登录，约 90 天有效期）

  • 切到「123网盘」点击扫码，用手机 123云盘 App 扫码确认即可拿到约 90 天有效期的访问凭证（同时支持分享链转存、磁力离线与外挂字幕落盘）。

4. 光鸭云盘（扫码登录或粘贴 Token）

  • 扫码登录（推荐）：自 2026-10 更新起，光鸭云盘已支持原生设备码二维码登录 —— 点击「生成二维码」，用手机 光鸭云盘 App 扫码即可自动获取 accessToken 与 refreshToken。

5. 天翼云盘（扫码登录或粘贴 SSON Cookie）

  • 点击「天翼云盘 → 生成二维码」，用手机 天翼云盘 App 扫码确认即可绑定个人云空间。

二、搜索源与服务配置（设置 → 资源与服务）

1. PanSou 网盘聚合搜索

  • Docker 部署版：已内置专属 pansou 容器，开箱即用，无需手动配置。
  • 桌面版：默认连接公共实例；如果你在 NAS 上自建了 PanSou，可在「设置 → 资源与服务 → PanSou」填入你的自建地址。

2. 海搜（Haisou）官方 API 补充源（可选）

  • 海搜覆盖了大量夸克、UC、百度、阿里、115、天翼、123、迅雷/光鸭等多平台分享链。在 iDataRiver 获取海搜 API Key 后填入「设置 → 资源与服务 → 海搜」，巡影会在每次搜索时将 PanSou 与海搜结果自动去重合并。

3. Prowlarr 磁力 / PT 索引器聚合（推荐 115 / 光鸭 / 123 用户开启）

  • 如果你连接了支持磁力离线的网盘（115、光鸭、123），强烈建议配置 Prowlarr 的 Base URL 与 API Key。Agent 搜索时会把 Prowlarr 的种子磁力与网盘分享链放在同一份快照里对比，遇到分享链死链或冷门老片时直接用磁力秒传落盘。

4. assrt.net（伪射手）外挂中文字幕（推荐开启）

  • 在 assrt.net 注册页面 免费注册并复制 32 位 Token 填入「设置 → 字幕来源」。当 Agent 获取欧美电影或日本生肉番剧时，会自动拉取简繁双语字幕包并改名对齐到视频文件旁。
