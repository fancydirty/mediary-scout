NAS / 软路由 iStoreOS / Linux Docker Compose 自动追剧部署指南

2026-10-29 更新 · 适用于群晖、飞牛 fnOS、绿联、极空间、威联通、Unraid、iStoreOS 软路由与 Linux VPS

如果你只是一台个人 Mac 或 Windows 电脑自用，直接下载 巡影 Mediary Scout 桌面版安装包 双击打开即可，无需安装 Docker。但如果你希望7×24 小时在后台自动巡检补齐在更剧集、手机随时打开网页点片、或者全家人多账号合用，推荐将巡影部署在 NAS、软路由（如 iStoreOS）或家庭小主机上。

一、两步启动完整 Docker 栈（含内置 PanSou 与自动更新器）

巡影的 docker-compose.yml 已经把四个核心容器打包好了：

  • web：Next.js 16 网页端 + 进程内后台获取/巡检 Worker；
  • postgres：PostgreSQL 17 持久化数据库（保存媒体库、剧集状态、网盘容量缓存与 Agent 记忆）；
  • pansou：开箱即用的内置 PanSou 网盘资源聚合搜索容器（已内置精选高命中频道配置）；
  • updater：网页端「一键更新 / 每日自动更新」守护助手（升级前自动执行 pg_dump 备份数据库，失败自动回滚）。
git clone https://github.com/fancydirty/mediary-scout.git
cd mediary-scout
docker compose up -d --build

构建启动完成后，在局域网浏览器打开 http://<你的设备IP>:3000 即可进入界面。

首次设密码安全护栏（局域网专属）

为了防止公网裸奔被陌生人抢注站主，第一次设置访问密码（或认领站主账号）只能在局域网内打开 http://<内网IP>:3000 完成。请勿在设好密码前把 3000 端口通过 UPnP 或端口转发直接暴露到公网。

二、国内网络构建加速（解决 DockerHub / npm 拉取慢）

如果你的 NAS 或软路由在直连 DockerHub 时超时，可以在启动前指定国内镜像前缀与 npm 镜像源（写在同目录的 .env 文件中）：

# .env（可选，国内无透明代理环境推荐配置）
DOCKER_MIRROR=docker.1ms.run/
NPM_REGISTRY=https://registry.npmmirror.com

配置后再执行 docker compose up -d --build，基础镜像与依赖包均走国内镜像高速拉取。

三、网页端一键更新与每日自动更新

部署完成后，后续版本迭代无需再 SSH 登录服务器敲命令：

  • 打开网页端 设置 → 更新，当 GitHub 发布新版本（如 v2026.10.29）时，页面会直接展示中文更新日志与「立即更新」按钮；
  • 你也可以开启「每日自动更新」（默认凌晨 04:00 检查）：更新助手会先等待正在进行的获取任务收尾、自动备份 PostgreSQL 数据库，然后拉取新版本构建切换；若新容器健康探针未通过，会自动回滚到旧版本。

四、出门在外用手机访问（Tailscale / Cloudflare Tunnel / Mediary Connect）

想在公司或地铁上用手机浏览器打开家里的巡影点片？有三种安全方式（均无需公网 IP）：

  1. Mediary Connect（最省心，设置页内置）：在「设置 → 远程访问」里输入你想要的二级域名前缀（如 myhome.mediary.uk），扫码即可自动开通 Cloudflare 加密隧道与 DNS，直接用手机浏览器输入网址 + 你的实例访问密码登录。
  2. 自建 Cloudflare Tunnel（免费）：在你自己的 Cloudflare 账号 Zero Trust 里创建一条 Tunnel 指向 http://localhost:3000。
  3. Tailscale / ZeroTier 异地组网（免费）：在 NAS 和手机上登录同一个 Tailscale 账号，直接通过虚拟内网 IP 访问。

五、开启全家多账号模式（可选）

如果家里人或朋友想共用这台服务器，但各自用各自的网盘、看各自的追剧海报墙，只需在 .env 中加一行：

MEDIA_TRACK_MULTI_USER=1

重启容器后，每个用户可以独立注册登录、绑定自己的网盘并拥有完全隔离的媒体库。
