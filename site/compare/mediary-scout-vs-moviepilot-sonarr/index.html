巡影 Mediary Scout vs MoviePilot / Sonarr / CloudDrive2：自动追剧工具怎么选？

2026-10-29 核实更新 · 客观对比云网盘 Agent 流与传统 PT 本地硬盘流的优缺点

很多想搭建家庭自动化影视库的朋友都会纠结：到底是上 MoviePilot / Sonarr + qBittorrent 这一套经典 PT/BT 自动化栈，还是用 巡影 Mediary Scout 走云网盘自动转存与离线秒传？

这两套方案并不是谁单纯替代谁，而是针对完全不同的存储介质与资源生态设计的。下面用一张完整对比表和具体场景帮你做决定。

二、诚实优缺点对比：什么时候选谁？

什么时候应该选 MoviePilot / Sonarr？

  • 你已经是重度私有 PT 玩家：手里有多个大站 PT 账号、家里有大容量 4 盘位/8 盘位 NAS 机械阵列和公网上传带宽，享受本地 LAN 蓝光原盘零缓冲直通播放。
  • 你不想依赖任何云网盘厂商或 LLM 接口：Sonarr / MoviePilot 用纯确定性的正则规则运行，不调用 AI 模型，只要规则写好就能零 Token 跑下去。

什么时候应该选巡影 Mediary Scout？

  • 你的主力存储是云网盘（夸克 / UC / 115 / 123 / 光鸭 / 天翼）：不想买几千块钱的大容量 NAS 机械硬盘，也不想应付 PT 站严苛的分享率考核和每月的保种电费。
  • 你厌倦了维护正则表达式和被黑盒分享包坑：网盘分享链的标题千奇百怪（比如把广告视频混在剧集里、或者文件夹名叫「新建文件夹」）。巡影的 Agent 会先转进临时 staging 目录，回读真实文件大小和集数，删掉广告和低码率重复集后再放进正式库。
  • 你手里有多块网盘，希望它们合体成一个库：比如夸克会员过期超额了，还有 UC 6TB、123 20TB、115 40TB 和光鸭 500TB。巡影会自动避开超额的夸克，优先在单块盘收齐，单盘不全时跨盘互补（参见 多网盘统一协作机制）。
  • 你想要开箱即用的桌面软件或极简软路由容器：巡影提供带 Apple 签名公证的 macOS 桌面版、Windows 桌面版，以及能在 2GB 内存软路由（如 iStoreOS）上流畅运行的 Docker 栈。

三、巡影 Mediary Scout 与 CloudDrive2 / AList / Infuse 是什么关系？

黄金互补搭档，而非竞争对手！

巡影 Mediary Scout 负责「找片、选片、转存、整理、追更入盘」；而 Infuse / VidHub / CloudDrive2 / AList / Emby 负责「把你网盘里整理干净的规范目录挂载出来播放」。

巡影在你的网盘里生成的目录结构天然符合媒体中心规范：

Mediary Scout/
├── Movies/
│   └── 坠落 (2022) {tmdb-985939}/
│       └── 坠落.Fall.2022.2160p.UHD.BluRay.HDR.mkv
├── TV/
│   └── 幻视任务 (2026) {tmdb-213375}/
│       └── Season 01/
│           ├── 幻视任务.S01E01.2160p.DV.mkv
│           └── ...
└── Anime/
    └── 学园默示录 (2010) {tmdb-56998}/
        └── Season 01/
            ├── [Snow-Raws] 学園黙示録 第01話.mkv
            └── [Snow-Raws] 学園黙示録 第01話.sc.ass

而且因为巡影所有的转存、改名和去重都走网盘官方 Web API 直接在云端完成（而不是通过 FUSE 本地挂载盘去全盘高频扫盘），不会触发网盘针对挂载扫盘的 403 风控冻结。等巡影把文件干干净净放进 Season 01 后，你打开 Apple TV / Mac / iPad 上的 Infuse 或 VidHub 直接点播即可！
