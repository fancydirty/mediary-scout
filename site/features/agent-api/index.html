Agent HTTP API：让 Claude Code、Codex、OpenClaw 直接操控你的网盘媒体库

2026-10-29 · 面向 AI Agent 与自动化工作流的原生接口

巡影 Mediary Scout 不仅自己内部是一个影视获取 AI Agent，它还向上层智能体（如 Claude Code、OpenAI Codex、ZCode、OpenClaw 或你自己的 Telegram/飞书机器人）暴露了一组极简的 /api/agent/* HTTP 接口。

启用后，你只需要在终端或聊天窗口里对你的个人 AI 助手说一句：「帮我让巡影把《葬送的芙莉莲》和《沙丘2》收进网盘，顺便看看现在队列里有什么在跑」，外部 Agent 即可通过 Bearer Token 直接调动巡影完成入队与状态跟踪。

一、如何获取 Agent API Token

打开巡影网页端的 设置 → 系统 → Agent API（或在环境变量中设置 MEDIA_TRACK_AGENT_TOKEN），点击生成 Token。所有请求在 Header 中携带：

Authorization: Bearer <你的_AGENT_API_TOKEN>

二、五大核心端点一览

HTTP 方法与路径功能说明
POST /api/agent/acquire按片名关键词或指定 tmdbId 搜索并自动将电影/剧集加入获取队列
GET /api/agent/library列出当前已追踪的全部电影、剧集、番剧及其已获取集数与缺集列表
GET /api/agent/activity查看当前正在排队或运行中的 Agent 获取任务进度及最近完成的通知
POST /api/agent/patrol立即触发一次全库日常缺集巡检（runScheduledType3Monitoring）
GET / PUT /api/agent/config读取（已脱敏）或更新实例的 AI 模型、搜索源、巡检时间与画质偏好

三、调用示例：一句话搜片并入队获取

curl -X POST http://localhost:3000/api/agent/acquire \
  -H "Authorization: Bearer $AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "幻视任务", "type": "tv"}'

返回结果会直接包含匹配到的 TMDB 信息、入队的 workflowRunId 与当前追踪季 ID，外部 Agent 可随后轮询 GET /api/agent/activity 汇报实时转存进度。
