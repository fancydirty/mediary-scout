多网盘统一协作获取与六盘实时余量保护机制

2026-10-29 · 适用版本：巡影 v2026.10.29 及以上

玩网盘追剧的用户手里往往不止一块网盘：有人平时用 115 网盘 或 光鸭云盘 秒传磁力蓝光原盘，有人用 123网盘 或 UC网盘 转存国产新剧分享链，还有人的 夸克网盘 曾经开过 6TB 会员、存了 1.3TB 剧集后会员到期退回 10GB 总额度（处于 -1.34 TB 超额冻结状态）。

如果工具把每块网盘割裂成孤立的工作区，你点一部剧之前还得先猜「这部剧在哪个网盘有资源？那块盘还有没有空间？」。巡影（Mediary Scout）通过统一多网盘协调器（MultiDriveStorageV2），让一个 AI Agent 同时统筹你已连接的全部网盘。

一、六大网盘实时容量探测与超额硬拦截

每次运行获取任务（以及打开设置页网盘面板）时，巡影都会通过各品牌的原生容量接口探测真实总额度与已用空间，并缓存在本地 drive_space_cache 表中：

网盘品牌容量探测机制典型真实状态示例Agent 准入决策
115 网盘user/space 总额与已用字节剩余 21.12 TB / 40.01 TB✅ 正常可写（分享链 + 磁力 + 字幕）
夸克网盘clouddrive/member 容量字段已超额 1.34 TB（共 10.0 GB）⛔ 禁止写入（提示词标红 + 沙盒入口硬拦截）
UC 网盘clouddrive/member 容量字段剩余 5.40 TB / 6.00 TB✅ 正常可写（UC 分享链）
光鸭云盘assets/v1/get_assets剩余 499.31 TB / 500.00 TB✅ 正常可写（光鸭分享链 + 磁力 + 字幕）
123网盘b/api/user/info 永久空间剩余 19.58 TB / 21.56 TB✅ 正常可写（123 分享链 + 磁力 + 字幕）
天翼云盘getUserInfo.action 个人云容量已超额 41.1 GB（共 30.0 GB）⛔ 禁止写入（超额硬拦截）

双重护栏：不靠大模型「自觉」，沙盒边界直接硬拦截

对于剩余空间 <= 0（已超配额或已满）或者剩余空间小于候选已知体积的网盘，不仅在系统提示词里明确标注 — 禁止写入，而且在沙盒 transferCandidate 工具入口设有机械门禁 SANDBOX_DRIVE_OUT_OF_SPACE —— 就算模型试图调用，也会在发起任何网盘网络请求前被当场拒绝，绝不往超额盘塞一字节数据。

二、多盘智能分配的 7 条铁律

当 PanSou、海搜和 Prowlarr 把所有已连接网盘的候选资源汇总成一份多品牌快照（每条候选标注 · 115、· 夸克、· UC、· 123、· 光鸭、· 磁力，并按每品牌轮转保底配额防止单一高产网盘挤掉其他网盘候选）交给 Agent 后，Agent 严格执行以下 7 条分配铁律：

  1. 剩余空间 <= 0 的网盘严禁落盘：余量数据的唯一作用就是排除装不下的盘。已超额网盘上的候选哪怕画质再高，也一律跳过。
  2. 默认单盘收齐（单盘优先，绝不无故拆盘）：先看有没有任何单块可用网盘能覆盖全部缺集。如果有，就只用那一块盘一次收齐，其余网盘一律不碰！在都能单盘收齐的候选里，按「资源画质与中字完整性更好 → 本剧历史在追主盘」挑选。
  3. 拆盘的唯一标准：拆完能拿到的总集数 > 单盘能拿到的集数：只有当没有任何单块可用网盘能收齐全部缺集时，才允许跨盘互补。例如美剧《幻视任务》已播 6 集，115 上只有 S01E01–E04 的 4K 杜比视界包，而 S01E05–E06 只有 123 网盘有分享链 —— 单盘最多只能拿 4 集，115 + 123 组合能拿齐 6 集，此时 Agent 自动将 E01–E04 落入 115、E05–E06 落入 123。
  4. 懒创建目录（零空目录污染）：MultiDriveStorageV2 只在真正发生转存或文件移动的那块网盘上按需创建 Title (Year) {tmdb-N}/staging 与 Season NN 目录；未参与落盘的网盘不会留下任何空文件夹。
  5. 严禁为了「均衡剩余空间」而拆盘：绝不会因为光鸭剩 499TB、115 剩 21TB 就把一部剧拆开平摊。
  6. 同一集绝不在两块网盘重复存两份：每一集只落一块网盘，杜绝跨盘冗余浪费。
  7. 在更剧主盘粘性与诚实上报：正在连载更新的剧集，日常巡检优先将新集继续落回该剧的历史在追主盘（保持整季目录集中）；只有原盘确实没有最新集或已满时，才用其他盘兜底补齐。如果某集的唯一候选位于已超配额的网盘上，系统会如实报告「对应网盘空间已满/超额」，绝不谎报成「暂未找到资源」。

三、跨盘副本表与统一媒体库视图

落盘完成后，你不需要去不同网盘工作区翻找：

  • 剧集详情页每集归属徽章：每个集数格子直接显示 已获取 · 115、已获取 · 123 或 已获取 · 光鸭云盘，鼠标悬停即可查看该集所在网盘与真实文件体积（如 115 · 6.3 GB）。
  • 电影详情页与通知卡片：电影详情页顶部徽章直接显示 已入库 · 光鸭云盘 及参数胶囊 网盘 光鸭云盘 · 体积 67.6 GB；跨盘互补入库的剧集在通知中心自动附带 跨盘分布：115 4 集 · 123 2 集 明细。
