AI 语义选片、一句话留言换源、assrt 自动补中文字幕与剧情搜片

2026-10-29 · 告别正则表达式维护的四个核心体验

传统追剧工具最让人头疼的不是「找不到资源」，而是「找到了错的资源却不知道」：同名老片混进新片、转存下来发现是无字幕生肉、或者某两集画面发蓝/音轨不对却没法单独重下。巡影（Mediary Scout）把这四件事全部交给了带沙盒工具链的 AI Agent。

一、一句话给 Agent 留言换源（全盘永久拉黑坏链）

在日常观影中，如果你发现某部电影是枪版假片，或者某部剧的第 13、24 集画面发蓝、音轨错位，你不需要去网盘里手动翻删再重搜：

  1. 直接在巡影的作品详情页留言板点选对应集数（或直接打字说「第 13 集画质发蓝，换一个版本」「这是无中字生肉，换带简中字幕的」），可选择「现在处理」或等下次日常巡检。
  2. Agent 启动换源任务后，先读取目标目录里的现有文件，调用 rejectCurrentSource 将坏文件的名称、体积以及当初转存它的原始分享链/磁力指纹（resourceLinkKey）写入全账号拒绝表（rejected_resources）。
  3. 随后 Agent 在排除坏链的候选池里挑选新资源转存，并在找到新版本前保护旧文件不被误删（避免没找到新源却把旧文件删空）。
  4. 被拒绝的坏源在所有已连接网盘上永久拉黑 —— 即便别的频道把同一条分享链换了个标题重发，未来任何巡检或换源也绝不会再次转存它。

二、外挂中文字幕自动补全与批量改名对位（assrt.net）

欧美电影与日本番剧的高画质蓝光原盘（如 [Snow-Raws] BD 1920x1080 HEVC FLAC 或 2160p UHD BluRay REMUX）往往没有内封中文字幕。只要你在「设置 → 字幕来源」填入免费的 assrt.net（伪射手） API Token：

  • 自动触发：对于非国产影视，系统在开跑前自动用裸片名预搜 assrt 字幕包，生成包含社区评分（★）、字幕组名称与语言标签（[简 繁 双语]）的字幕快照文档。
  • 云端直链离线落盘：在支持外链离线的网盘（115 网盘、光鸭云盘、123网盘）上，Agent 调用 transferSubtitle 直接把字幕包拉进网盘 staging 目录，全程不经过本地硬盘。
  • 一键批量同名前缀对齐：Agent 调用一次 renameSubtitle 批量将全季 12 集或 24 集的 .sc.ass / .tc.ass / .srt 改名为与对应视频文件完全一致的前缀（例如 [Snow-Raws] 学園黙示録 第01話 (...).sc.ass），随后连同视频一起移入 Season 01，让 Infuse、VidHub、Kodi、IINA 或 Emby/Jellyfin 播放器打开即自动挂载中文字幕！

三、黑盒转存回读验证与高低码率智能去重

网盘分享生态里大量存在两类坑：① 标题只写片名的「黑盒文件夹」；② 一个分享包里同时塞了 4KHQHDR（6GB/集） 和普通 4KHDR（1.5GB/集） 双份文件，外加「关注公众号.mp4」推广诱导小视频。

巡影的 Agent 严格遵守「证据先行，回读验证」：

  • 所有转存先进入临时的 staging-<runId> 沙盒目录；
  • Agent 调用 inspectStaging 读取真实落地的文件树与精确字节大小（sizeBytes）；
  • 发现同一集有高低码率两份文件时，先调 deleteFiles 删掉低码率小文件与推广垃圾，只把真正的高码率正片 moveToSeason 移入季目录，最后 discardStaging 销毁临时目录。

四、剧情描述找片 & 动漫民间分季集号自动对齐

  • 记不清片名？直接搜剧情描述：在搜索框输入「男主带着小绿瓶修仙的国漫」或「咒术回战 死灭回游」，系统会自动结合你的 AI 模型与联网搜索将其解析为准确的 TMDB 作品（如《凡人修仙传》《咒术回战》）。
  • 官方不分季 vs 字幕组分季自动映射：像《死神 千年血战篇》《海贼王》这类作品，TMDB 官方把几十集全部归在同 1 季，而网盘发布组按「诀别谭」「相剋谭」分季从 E01 重新编号。巡影 Agent 内置网页查证工具（searchWeb），在获取时自动查清篇章对应的绝对集号区间，精准落盘不漏集。
