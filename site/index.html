常见问题（FAQ）

巡影 Mediary Scout 会乱动我的网盘文件吗？

不会。系统内置严格的目录写作用域守卫（Write Scope Guard），只允许在专用媒体库目录（Mediary Scout/{Movies,TV,Anime}）内创建和移动文件，绝不触碰你网盘里的其他个人文件夹。全程每一步工具调用在「活动」页实时可见。

我的网盘账号凭证和 AI Key 存在哪里？

全部保存在你自己电脑（桌面版）或你自己的服务器（Docker 版）本地数据库里，作者与任何外部服务器都碰不到。

使用要花钱吗？没有 AI 模型 API Key 能直接用吗？

软件免费开源；出厂已内置 Kilo 公共免费 AI 模型池，无需注册或填 Key 就能直接搜片获取。如果你追求更快的推理速度，也可以在「设置 → AI 模型」里填入 DeepSeek、智谱 GLM、小米 MiMo 等任意 OpenAI 兼容接口。

支持哪些网盘？多块网盘同时连接是怎么分配的？

支持 夸克、UC、115、123、光鸭、天翼 六大网盘（均支持手机扫码登录）。你可以同时绑定多块网盘，系统会自动查询每块盘的剩余容量（会员到期超额的盘自动禁止写入），遵循「单盘能收齐绝不拆盘、单盘都不全时跨盘互补收齐」的原则。不知道主力用哪个盘？看 六大网盘实测资源量对比 与 多网盘统一协作机制详解。

巡影 Mediary Scout 和 MoviePilot / Sonarr 有什么不同？

MoviePilot 和 Sonarr 的核心是「PT 种子下载到本地硬盘 + 正则表达式整理硬链接」；而巡影 Mediary Scout 专为「国内云网盘分享链转存 + 磁力秒传离线」设计，零本地硬盘占用、无需公网 IP 保种、无需手写正则规则。详见 Mediary Scout 与 MoviePilot / Sonarr 深度对比。

Windows 提示「Windows 已保护你的电脑」？

Windows 商业代码签名证书价格高昂，个人开源项目未购买商业签名所致（macOS 版已签名公证）。点击「更多信息 → 仍要运行」即可；每个安装包发布前均经过 GitHub Actions 真机安装冒烟验证。
