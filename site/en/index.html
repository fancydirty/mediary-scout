Why Mediary Scout? Evidence-Driven Cloud Media Acquisition

Traditional media automation tools (like Sonarr, Radarr, or MoviePilot) assume you maintain local multi-bay NAS hard drives, BitTorrent/PT clients, and brittle regular-expression rules. In practice, cloud drive share links and instant magnet offline transfers offer massive resource pools with zero local disk footprint—but share titles are noisy, dead links are common, and multi-season packs contain nested folders or promotional junk.

Mediary Scout (巡影) replaces fragile regex pipelines with a tool-using AI agent running inside a strict write-scoped sandbox:

  • Unified Multi-Drive Orchestration & Quota Protection: Connect Quark, UC, 115, 123Pan, GuangYaPan, and Tianyi simultaneously. Before every run, Mediary Scout probes each drive's remaining capacity. Drives that are full or over-quota (for example, an expired Quark SVIP account at -1.34 TB) are hard-blocked at the sandbox gate (SANDBOX_DRIVE_OUT_OF_SPACE).
  • Single-Drive Priority, Cross-Drive Complement: If any single active drive can cover all missing episodes of a show, the agent uses only that drive and creates zero folders on other drives. When no single drive has the full season (e.g., Episodes 1–4 on 115 and Episodes 5–6 on 123Pan), the agent automatically combines both drives and records per-episode drive ownership in the unified library UI.
  • Black-Box Verification & Dedup: Transfers land in an isolated staging directory first. The agent inspects the real materialized video files and file sizes, deletes ad files or lower-bitrate duplicates, moves verified episodes into Season NN, and cleans up staging.
  • External Subtitle Completion (assrt.net): When a foreign movie or anime lands without Chinese subtitles, the agent automatically searches assrt.net, downloads matching subtitle packages into the drive, batch-renames .ass / .srt files to match the video filenames, and places them alongside the videos.
  • User Message Source Replacement & Agent Memory: Unhappy with an acquired file? Leave a natural-language note on the show's detail page (e.g., "Episode 3 has out-of-sync audio, replace it"). The agent rejects the old source, blacklists its share/magnet fingerprint across all drives, and fetches a clean replacement.

Installation: Desktop App or Docker Compose

1. Desktop App (macOS Apple Silicon & Windows x64)

Download the latest installer from GitHub Releases. The macOS .dmg is signed and notarized by Apple. The app bundles its own SQLite database and defaults to Kilo Code's free LLM pool—just scan a QR code to connect your cloud drive in Settings and start acquiring titles.

2. Docker Compose (NAS / Home Server / iStoreOS Router)

git clone https://github.com/fancydirty/mediary-scout && cd mediary-scout
docker compose up -d

This starts the Next.js web UI + in-process background worker, PostgreSQL, a bundled PanSou search instance, and the one-click auto-updater on port 3000.
