# 搜索与网页查证

本项目的搜索走两条路：**片名精确查找**用 TMDB，**描述性查找与官方不分季的作品**用网页搜索。

## 搜索框：描述也能找

在搜索框里可以：

- 直接搜片名/剧名（TMDB 精确匹配，最快）。
- 搜剧情描述，例如 `男主带着小绿瓶修仙的国漫`、`白敬亭科幻喜剧`。
- 只记得民间季名/篇章名，例如 `咒术回战 死灭回游`、`药屋少女的呢喃 第三季`。

后两种在 TMDB 里查不到，于是：

1. 先从搜索词里去掉 `第N季 / Season N / 上篇 / 下篇 / 完结篇` 这类后缀再查一次 TMDB（免费、确定，最常见的情况在这一步就解决）。
2. 仍然 0 结果时，用**你自己在「设置 → AI 模型」里配的模型**把描述翻成几个精确片名，再拿这些片名查 TMDB，最后照常出卡片。结果页会写明「已按『XXX』搜索」。

这条兜底用的是你的模型和你的额度：没配自己的模型时不会消耗任何东西，搜索就只是片名查找。若你的模型端点就是 DeepSeek 官方 API，网页搜索走 DeepSeek 自家的搜索接口（用你自己的 key 计费）。

## 获取 agent 的网页工具

获取/巡检的 agent 有两个只读工具：

- `researchTitle({ query })` — 查作品的其他译名，或查「<作品> 第二季对应第几集到第几集」。
- `readTitleReference({ urls })` — 读来源页，确认译名与季集对应。

规则固定写在系统里：

- **只作参考**：网页结果永远不会变成可转存候选，也不能证明已经获取到资源。
- **每次获取合计最多 4 次**，单次超时 20 秒；失败作为工具错误返回，agent 继续用已有资源证据。
- **临时目录恢复（staging recovery）运行不给这两个工具**。
- 网页正文被当作不可信数据，不能当指令执行。
- 只要你的模型端点是 DeepSeek 官方 API，就用 DeepSeek 的搜索；否则用 Parallel 的匿名（免 key）搜索服务。

## 官方不分季的作品（动漫画常见）

有些作品官方从未按季编号，TMDB 因此把它们存成一整段绝对集号，而资源组、字幕组和观众按「第二季 / 死灭回游」这类名字分块。例如：

| 作品 | 民间叫法 | TMDB 绝对集号 |
| --- | --- | --- |
| 咒术回战 | 第二季（怀玉·玉折／涩谷事变） | S01E25–E47 |
| 咒术回战 | 死灭回游 | S01E48–E59 |
| 药屋少女的呢喃 | 第二季 | S01E25–E48 |
| 药屋少女的呢喃 | 第三季 | S01E49–E60 |

获取 agent 被明确告知：**这类「季名不匹配」不是另一个作品，也不是该跳过的结果**。它会用 `researchTitle` 查清区间，再按本任务跟踪的绝对集号落盘 —— 库里的主键仍然是 TMDB 的数字，民间季名只用于搜索和匹配。以前因为季名对不上就直接放弃、把缺集永远留着的做法已被明确禁止。

## 关闭网页查证

不需要任何开关：没有配置自己的模型时，搜索框的描述解析不会发生；获取 agent 的网页工具仍可用（免 key 的匿名搜索），但不影响转存。

如果你完全不希望任何请求离开本机，可以在部署主机/容器上阻断 `search.parallel.ai` 与 `api.deepseek.com`，两者失败都会被当作「没有网页证据」，获取流程照旧。
