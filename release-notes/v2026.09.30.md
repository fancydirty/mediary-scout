# v2026.09.30

Docker 部署从这个版本起可以在网页里更新。从更早的版本升上来，需要在部署目录手动运行一次 `./scripts/deploy.sh`，之后的版本都在设置页「更新」里点一下就行。

这个版本改了更新助手本身：如果你的实例已经用上了一键更新（跟着 main 部署的），更新完成后在部署目录运行一次 `docker compose up -d --build updater`。

- 新增 Docker 部署可以在设置页「更新」里一键更新：先暂停新的获取任务，等进行中的做完再换；新版本没通过自检会自动回到原来的版本
- 新增 Docker 部署可以打开「每天自动更新」并选一个整点，有新版本时到点自动更新；同一个版本连续两次没更新成功就不再自动重试
- 改进 设置页顶部的新版本提示只看正式发布的版本（桌面版也会提示），点开直接进「更新」；原来那段「复制给本地 Agent」的升级指令去掉了
- 修复 123 网盘在别处登录被挤下线时，卡片会提示重新扫码，不再只显示一串错误代码
- 修复 网盘卡片上「测试连接」按钮不再被旁边的提示挤成两行
