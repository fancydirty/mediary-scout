# v2026.10.04

这个版本改了更新助手本身：已经用上一键更新的实例，更新完成后在部署目录运行一次 `docker compose up -d --build updater`，设置页「远程访问」里的一键接入才能用（没升级更新助手也能接入，页面会给一条命令，在部署目录运行即可）。

- 新增 Docker 部署可以在设置页「远程访问」里直接开通 Mediary Connect：填邮箱、在邮件里点确认、微信支付、选一个名字，再点「接入」就能从外网打开，不用再到终端里粘命令
- 修复 开了远程访问的实例，第一次设访问密码、认领站主只能在局域网里做，外网访客不能抢先设密码
- 修复 新一季或新剧刚开播时，排期里还没播的集不再算成已播；之前多算的已播数会自己降回来
- 修复 TMDB 删掉或合并某一季时，巡检按剧集分组还原这一季的集数，不再拿旧数字天天白跑
- 修复 巡检找到的电影结果放进每日汇总，不再每次巡检单独推一条通知
- 修复 123、光鸭、天翼网盘上转存失败留下的临时文件夹，系统也能自己清掉了
